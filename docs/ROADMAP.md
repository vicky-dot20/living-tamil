# Roadmap

The roadmap follows evidence, not feature count.

## Now: make the MVP trustworthy and testable

- Review the Five Landscapes journey with Tamil and subject experts.
- Resolve provenance and reuse rights for modern Kural commentaries and English meanings.
- Add lightweight, privacy-conscious completion and return metrics.
- Run moderated comprehension tests with 10–20 target users.
- Improve onboarding, direct sharing, accessibility, loading, and API fallbacks.

## Next: prove the journey habit

- Publish two or three thoroughly reviewed journeys.
- Measure continuation, return, completion, saves, shares, and corrections.
- Add feedback and correction flows.
- Add PWA/offline support where it improves real use.

## Later: expand only from validated demand

- Contextual reader and vocabulary-through-culture tools.
- Diaspora family learning experiments.
- More periods, genres, voices, dialects, audio, and maps.
- Contributor editorial dashboard and reviewer workflow.

Not planned before validation: a generic chatbot, social network, mass archive import, or universal Tamil knowledge graph.
