# Security policy

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in a public issue. Use GitHub's **Security → Report a vulnerability** feature to submit a private security advisory. Include the affected route or component, reproduction steps, impact, and a suggested mitigation if known.

Never include real API keys, access tokens, passwords, private user data, or production credentials in a report or pull request. Living Tamil currently uses public data APIs and requires no client-side secrets.

Security fixes target the latest `main` branch. Maintainers will acknowledge a valid report when available, investigate it, and coordinate disclosure after a fix. This volunteer project cannot promise a fixed response time.
