# Living Tamil

An experimental, mobile-first cultural discovery product for young Tamil speakers.

Version 0 contains one guided discovery: **Why did Sangam poets connect mountains with secret love?**

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Editorial status

The interface and reading experience are a product prototype. Cultural and literary content must receive scholarly review before public editorial publication. Maintain a source and licence record for every text, translation, image and recording added to the project.
